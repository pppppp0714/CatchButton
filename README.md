# 버튼잡기게임(C# 코딩)
## 개요
- C# 프로그래밍 학습
- 핵심기능 : 마우스가 닿으면 랜덤한 위치로 이동하는 버튼, 버튼을 클릭하면 메시지 출력, 버튼의 이동과 클릭 시 특정 효과음 재생
- 화면구성 : 화면 중앙에 '나를 잡아봐' 텍스트가 입력된 버튼
