# 버튼 잡기 게임 (C# 코딩)
## 개요
- C# 프로그래밍 학습
- 핵심 기능 : 마우스가 닿으면 랜덤한 위치로 이동하는 버튼, 버튼을 클릭하면 메시지 출력, 버튼의 이동과 클릭 시 특정 효과음 재생, 점수 기능(버튼이 위치가 이동할 시 -10, 버튼을 클릭할 시 +100), 버튼을 클릭할 시 난이도 증가(버튼의 크기 감소), 게임오버 및 재시작 기능
- 화면 구성 : 화면 중앙에 '나를 잡아봐' 텍스트가 입력된 버튼

## 구현 시 어려웠던 점
- 버튼의 이동과 클릭 시에 효과음을 재생하는 코드를 추가할 때 어려움을 겪었지만, 코파일럿의 도움을 받아 해결하였습니다.
- 버튼 클릭이 성공했을 때 '축하합니다~!' 문구를 출력하는 코드를 추가할 때 어려움을 겪었지만, 코파일럿의 도움을 받아 해결하였습니다.
- 버튼 클릭이 성공했을 때 버튼의 크기를 축소하는 코드를 추가할 때 어려움을 겪었지만, 코파일럿의 도움을 받아 해결하였습니다.
- 점수 기능을 추가할 때 어려움을 겪었지만, C#을 공부하여 해결하였습니다.
- 게임 오버 시 추가적인 입력이 불가능한 상태로 변경하는 코드를 추가할 때 어려움을 겪엇지만, 코파일럿의 도움을 받아 해결하였습니다.
- 재시작 버튼을 눌렀을 때 게임의 초기 상태로 돌아가는 코드를 추가할 때 어려움을 겪었지만, 코파일럿의 도움을 받아 해결하였습니다.
